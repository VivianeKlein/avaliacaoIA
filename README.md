# Cardápio digital — Go Bite

## Descrição

Protótipo responsivo de cardápio digital para uma lanchonete. O cliente pode consultar seis produtos fictícios em três categorias, filtrar o catálogo, adicionar itens ao carrinho, ajustar quantidades e visualizar subtotais e o total. Ao confirmar, o sistema apresenta um resumo simulado do pedido e impede a confirmação de um carrinho vazio.

O catálogo e o carrinho são mantidos no navegador durante a sessão. Não há servidor, persistência de pedidos ou processamento de pagamentos.

## Como executar

1. Abra a pasta `frontend/`.
2. Abra `index.html` em um navegador moderno.
3. Escolha uma categoria, adicione produtos e use o carrinho para ajustar quantidades ou confirmar o pedido.

Não é necessário instalar dependências nem iniciar um servidor para executar o protótipo.

## Ferramentas utilizadas

- **HTML5** para a estrutura e acessibilidade da página.
- **CSS3** para o visual e o layout responsivo.
- **JavaScript** para filtros, carrinho, cálculos e confirmação simulada.
- **Visual Studio Code** como ambiente de desenvolvimento.
- **Git** para controle de versão.
- **GitHub Copilot** como assistente de IA durante a criação do protótipo.
- **Node.js** para verificar a sintaxe e testar as interações; não é necessário para abrir a aplicação.
- **Navegador web moderno** para executar e visualizar o protótipo.
