# Backend

Este protótipo não possui backend: o catálogo está definido no JavaScript do frontend, e o carrinho existe apenas durante a sessão no navegador. A confirmação é simulada e não envia nem persiste pedidos.

Esta pasta documenta o escopo atual e pode receber uma API em uma etapa futura. Para a descrição geral da solução, instruções de execução e ferramentas utilizadas, consulte o [README principal](../README.md).
